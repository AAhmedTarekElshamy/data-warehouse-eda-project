# 📊 SQL Exploratory Data Analysis & Analytics Project

## 📌 Project Overview
This project focuses on performing **Exploratory Data Analysis (EDA)** and building **Business Intelligence (BI) Metrics** on a Data Warehouse (`Gold Layer` / Star Schema). The main goal is to transform raw transactional data into actionable business insights, customer segments, and production-ready SQL reporting views.
